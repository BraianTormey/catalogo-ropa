# Catálogo de ropa

Página estática para mostrar la ropa disponible con precio y stock. Al tocar una prenda se abre una galería de fotos y un botón para escribir a la vendedora por WhatsApp.

## Cómo actualizarla
- **Prendas, precios y stock:** editá `productos.js`.
- **Número de WhatsApp:** variable `WHATSAPP` en `productos.js`.
- **Fotos:** guardalas en la carpeta `fotos/` y agregalas a la lista `fotos` de cada prenda.

## Verla en tu computadora
Abrí `index.html` en el navegador.

## Publicarla gratis
En GitHub: Settings → Pages → Deploy from a branch → `main` / `(root)`.
